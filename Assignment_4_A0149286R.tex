\section{General Induced Subgraph Game}
\begin{proof}
    We can consider the elements in the set of edges 
    $e\in E,e=\{a,b\} \subseteq N$ where $a,b$ are players.
    Then we can define the induced subgraph game to be
    a weighted sum of ultimatum games
    \[v(S)=\sum_{e\in E} w(e)u_e(S)\]
    where $u_e$ is the ultimatum game for the players $a,b$. 
    Then
    \begin{equation}
    \begin{aligned}
        Sh_i(v)&=\sum_{e\in E} w(e)Sh_i(u_e) \quad\text{(by linearity)}\\
        &= \sum_{e\in E_i} w(e)Sh_i(u_e) \quad\text{(by dummy property)}\\
        &= \sum_{e\in E_i} w(e)\cdot\frac{1}{2} 
        \quad\text{(by symmetry/efficiency)}\\
        &= \frac{1}{2} \sum_{e\in E_i} w(e)
    \end{aligned}
    \end{equation}
\end{proof}

\subsection{Weighted Voting Game}
Let $N=\{1,2,3,4,5,6\}$. Observe that we have
\[\forall i \in N : \sum_{j\in N\backslash\{i\}} w_j\geq 5\]
Thus, the game has no veto players. This game is also a simple game,
so by the theorem proven in the lectures slides, there does not exist a core.\\
Player 1 can only be pivotal when preceeded by players whose combined weight
is exactly 4. So they are preceeded by
\[\{2,6\},\{3,6\},\{2,3,4\},\{2,3,5\},\{4,5\}\]
By symmetry, $Sh_1=Sh_2=Sh_3$. Then
\[Sh_1=Sh_2=Sh_3=\frac{5\times 2!\times 3!}{6!}=\frac{1}{12}\]
Player 4 can only be pivotal when preceeded by players whose combined weight
is either 3 or 4. So they are preceeded by 
\[\{6\},\{1,5\},\{2,5\},\{3,5\},\{1,2,3\},
\{1,2,5\},\{1,3,5\},\{2,3,5\},\{1,6\},\{2,6\},\{3,6\}\]
By symmetry, $Sh_4=Sh_5$. Thus,
\[Sh_4=Sh_5=\frac{4!+10\times 2!\times 3!}{6!}=\frac{1}{5}\]
By efficiency, $\sum_{i\in N} Sh_i =1$. So
\[Sh_6=1-\frac{3}{12}-\frac{2}{5}=\frac{7}{20}\]
